# 단어 3 — 작은 창에 띄워 두는 영어 단어 암기 앱

iPad에서 영상을 보거나 필기하는 동안 옆에 작은 창으로 띄워 두고 **단어 3개를 계속 보는** 용도의 웹앱(PWA)입니다.
빌드 도구 없이 순수 HTML/CSS/JS로 만들었고, 오프라인에서도 동작합니다.

```
index.html      화면 구조 (집중 화면 + 설정)
style.css       유동 글자 크기(clamp), 라이트/다크 테마
app.js          모든 동작 (데이터는 localStorage에 저장)
manifest.json   홈 화면 앱 정보 (display: standalone)
sw.js           서비스 워커 (오프라인 캐시)
icons/          앱 아이콘 PNG
tools/make_icons.py   아이콘 생성 스크립트 (다시 만들 때만 필요)
```

## 기능

- **집중 화면:** 단어 카드 3장이 창 높이를 1/3씩 나눠 가집니다. 폭 280px 정도의 좁은 창에서도 스크롤이 생기지 않습니다. 창이 커지면 글자도 커지고, 글자가 카드에 다 들어가지 않으면 그 카드만 자동으로 줄어듭니다.
- **상단 버튼 3개**
  - **모드 전환:** 누를 때마다 `모두 보기 → 뜻 가림 → 영어 가림` 순서로 바뀝니다. 가린 모드에서는 카드를 탭하면 그 카드의 가린 부분이 보이고, 다시 탭하면 가려집니다.
  - **다음 3개:** 다음 묶음으로 넘어갑니다.
  - **⚙︎ 설정:** 설정 화면을 엽니다.
- **카드 버튼**
  - 🔊 발음 듣기 (영어 음성)
  - ✓ 외웠음: 설정에서 "외운 단어: 빼기"를 고르면 다음 묶음부터 나오지 않습니다(기본값).
  - ? 헷갈림: 더 자주 나옵니다. 랜덤에서는 3배 자주 뽑히고, 순서대로에서는 두 묶음마다 한 번씩 섞입니다.
- **설정 화면**
  - 테마(시스템/라이트/다크)
  - 다음 묶음 순서(순서대로/랜덤)
  - 글자 크기 슬라이더
  - 자동 넘김(끄기/30초/1분, 기본은 끄기)
  - 외운 단어 빼기/포함
  - 화면 꺼짐 방지(Wake Lock)
  - 단어 추가·수정·삭제
  - 여러 단어 붙여넣기
  - JSON 내보내기/가져오기
  - 샘플 단어로 초기화
- **저장:** 마지막 모드, 현재 위치와 묶음, 모든 설정이 저장되어 다시 열면 이어서 봅니다.
- **외장 키보드:** `→` 또는 `N` 키로 다음 묶음, `M` 키로 모드 전환.

### 여러 단어 붙여넣기 형식

한 줄에 하나씩, **첫 번째 쉼표**(또는 탭) 앞이 영어, 뒤가 뜻입니다. 뜻 안에는 쉼표가 있어도 됩니다.

```
apple, 사과
run, 달리다, 운영하다
```

- 형식이 틀린 줄(쉼표가 없거나 한쪽이 비어 있는 줄)은 건너뛰고, 몇 줄을 건너뛰었는지 알려 줍니다.
- 이미 있는 영어 단어(대소문자 무시)도 건너뜁니다.
- 엑셀이나 Numbers에서 두 열을 복사해 붙여넣어도 탭으로 구분되어 그대로 들어갑니다.

### JSON 가져오기 형식

내보낸 파일(`{"words": [{"en": "...", "ko": "...", "status": "..."}]}`)이나 `[{"en": "apple", "ko": "사과"}]` 형식의 배열을 가져올 수 있습니다. 가져올 때는 기존 단어에 합쳐지고, 같은 영어 단어는 가져온 내용으로 갱신됩니다.

## 1. 로컬에서 테스트하기

서비스 워커는 `file://`로는 동작하지 않으므로 간단한 웹 서버로 엽니다.

1. 터미널에서 이 폴더로 이동합니다.
   ```bash
   cd Code-C
   ```
2. 웹 서버를 실행합니다. 아래 중 편한 것 하나를 쓰면 됩니다.
   ```bash
   python3 -m http.server 8000
   # 또는
   npx serve .
   ```
3. 브라우저에서 `http://localhost:8000`을 엽니다.
4. 개발자 도구의 반응형 모드에서 폭을 280~400px로 줄여 카드 3장이 스크롤 없이 보이는지 확인합니다.
5. 오프라인 동작을 확인합니다.
   1. 개발자 도구 → Application(애플리케이션) → Service Workers에서 등록됐는지 확인합니다.
   2. Network 탭에서 "Offline"을 켭니다.
   3. 새로고침해도 앱이 열리면 정상입니다.

> 같은 Wi-Fi의 iPad에서 `http://<컴퓨터 IP>:8000`으로 화면은 볼 수 있습니다. 하지만 HTTPS가 아니라서 서비스 워커(오프라인)와 화면 꺼짐 방지는 동작하지 않습니다. 실제 설치는 아래 GitHub Pages(HTTPS)로 하세요.

## 2. GitHub Pages로 배포하기

1. 이 파일들이 GitHub 저장소의 기본 브랜치(`main`) 루트에 있도록 커밋하고 푸시합니다. 작업 브랜치에 있다면 Pull Request로 `main`에 병합합니다.
2. GitHub에서 저장소 → **Settings** → 왼쪽 메뉴 **Pages**로 갑니다.
3. **Build and deployment**에서 다음과 같이 고르고 **Save**를 누릅니다.
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`, 폴더 `/ (root)`
4. 1~2분 뒤 같은 화면 위쪽에 주소가 표시됩니다(예: `https://<사용자명>.github.io/<저장소명>/`).
5. 그 주소를 열어 앱이 뜨는지 확인합니다.

모든 경로가 상대 경로(`./`)라서 `/<저장소명>/` 같은 하위 경로에서도 그대로 동작합니다.

**업데이트할 때:** 파일을 고쳐 푸시하면 몇 분 뒤 반영됩니다. 앱은 캐시를 먼저 보여 주고 뒤에서 새 파일을 받아 두기 때문에, **앱을 한 번 닫았다가 다시 열면** 새 버전이 보입니다. 캐시할 파일 목록(`sw.js`의 `ASSETS`)을 바꿨다면 `sw.js`의 `CACHE` 이름(`vocab3-v1` → `vocab3-v2`)도 올려 주세요.

## 3. iPad Safari에서 "홈 화면에 추가"하기

1. iPad의 **Safari**에서 GitHub Pages 주소를 엽니다.
2. 주소창 옆의 **공유 버튼**(네모에서 화살표가 위로 나온 아이콘)을 누릅니다. 주소창 오른쪽의 `···` 메뉴 안에 있을 수도 있습니다.
3. **홈 화면에 추가**를 누릅니다.
4. 이름을 확인합니다(기본: "단어 3"). **웹 앱으로 열기** 스위치가 보이면 켜 둡니다.
5. 오른쪽 위 **추가**를 누릅니다.
6. 홈 화면에 생긴 **단어 3** 아이콘으로 엽니다. 주소창 없이 앱처럼 열리면 성공입니다.
7. 한 번 열고 나면 오프라인에서도 열립니다.

> **주의:** 홈 화면 앱과 Safari 탭은 저장 공간이 따로입니다. Safari에서 넣은 단어는 홈 화면 앱에 보이지 않습니다. 옮기려면 설정의 **JSON 내보내기**로 파일 앱에 저장한 뒤, 홈 화면 앱에서 **JSON 가져오기**를 하세요.

## 4. 작은 창으로 영상/필기 앱 옆에 나란히 두기 (iPadOS 26)

iPadOS 26에서는 앱을 자유 크기 창으로 띄울 수 있습니다.

1. **창 모드를 켭니다.**
   1. **설정** 앱 → **멀티태스킹 및 제스처**로 갑니다.
   2. **창 앱**(Windowed Apps)을 고릅니다. 스테이지 매니저를 써도 됩니다.
2. **영상 앱이나 필기 앱을 먼저 엽니다.**
3. **단어 3을 엽니다.** 홈 화면이나 Dock에서 단어 3 아이콘을 누르면 창으로 열립니다. Dock에 끌어다 두면 꺼내기 편합니다.
4. **창 크기를 줄입니다.** 창의 **오른쪽 아래 모서리**를 잡고 끌어 폭 300px 안팎의 세로로 긴 창으로 만듭니다.
   - 창이 좁아도 카드 3장이 한눈에 보이고, 글자는 창 크기에 맞춰 자동으로 줄거나 커집니다.
5. **창 위치를 정합니다.** 창의 위쪽 가장자리를 잡고 화면 오른쪽(또는 왼쪽) 끝으로 옮깁니다.
6. **다른 창도 정리합니다.** 영상/필기 앱 창의 크기를 남은 공간에 맞춥니다.
   - 창 왼쪽 위 **창 제어 버튼**(신호등 모양 점 3개)을 길게 누르면 화면 왼쪽/오른쪽 절반 등으로 나란히 배치하는 메뉴가 나옵니다.
7. **곁눈질용으로 다듬습니다.**
   1. 단어 3의 **⚙︎ 설정 → 글자 크기**로 보기 편한 크기를 맞춥니다.
   2. 손을 대지 않고 보려면 **자동 넘김**을 30초나 1분으로 켭니다.
   3. 영상을 보는 동안 화면이 꺼지지 않게 하려면 **화면 꺼짐 방지**를 켭니다.
8. 공부할 때는 상단의 모드 버튼으로 **뜻 가림/영어 가림**을 고르고, 떠올려 본 뒤 카드를 탭해 확인합니다.

메뉴 이름은 iPadOS 버전과 언어 설정에 따라 조금 다를 수 있습니다.
